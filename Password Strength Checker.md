# &#x20;**Password Strength Checker**





##### About the Project



.**Password Strength Checker is a Python program that checks how strong a password is using entropy calculation and security rules.**



##### *Features*

Checks password length.

Checks uppercase and lowercase letters.

Checks numbers and special characters.

Calculates password entropy.

Detects common passwords.

Classifies password strength as Weak, Moderate, Strong, or Exceptional.

Gives suggestions to improve password security.





##### *Technologies Used*

Python 3

VS Code

CMD



###### *How to Run*

Open CMD.

Go to the project folder.

Run this command:

bash

python password\_checker.py



Enter your password.

View the password strength result.
